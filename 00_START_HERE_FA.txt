SALLY | سورس کامل یکپارچه Shop برای بیلد و تست — ۲۰۲۶/۱۰/۳۰
==========================================================

به‌روزرسانی ۲۰۲۶/۱۰/۳۱: Landing با همان عکس مدلِ ست کرم انتخاب‌شده آماده شد.
شماره‌ها و آمار تزئینی حذف شدند؛ میله مشکی رگال و آویز عکاسی‌شده هر لباس برگشتند.
سه نمای هر هشت لباس، گالری ۲۴ عکس، هاور/کلیک و قاب موبایل در مرورگر بررسی شدند.
اصلاح تازه پس از بازخورد شما: شانه کامل آویز و هم‌پوشانی با یقه برای هر لباس تنظیم شد.
عکس‌های اصلی، طرح هودی و قلابِ عکاسی‌شده حفظ شدند؛ پذیرش نهایی ظاهر با شماست.
تازه‌ترین اصلاح: مدل به تیتر نزدیک‌تر شد و پروفایل https اول فهرست قرار گرفت.
ورود مشتری با https روی پورت 7092 توسط شما موفق گزارش شد.
SALLY_TEST روی پورت 7143 فقط برای دیتابیس مستقلِ از قبل آماده‌شده است.
انتخاب قبلی Visual Studio ممکن است باقی بماند؛ یک بار https را دستی انتخاب کنید.
Build این تغییر جدید اینجا اجرا نشده است.

این ZIP کل پوشه Shop است؛ Patch یا PREVIEW تنها نیست.
شروع کامل: SALLY_TEST_PACKAGE_FA.md
وضعیت قابلیت‌ها و تست‌های باز: 00_WORKSPACE_STATUS_FA.md
تطبیق با ZIP قبلی: SALLY_PACKAGE_MANIFEST.json

با درخواست جدید شما، این سورس برای جایگزینی پوشه قبلی و تست بیلد تحویل می‌شود.
این تحویل به معنی پایان همه تسک‌ها یا موفقیت Build/SQL/SMTP نیست.

الان فقط قدم اول:
  ۱) Visual Studio و سایت قبلی را ببندید.
  ۲) پوشه فعلی Shop را با نامی مثل Shop_BACKUP_20261030 نگه دارید.
     دیتابیس، بکاپ SQL و داده‌های قبلی حذف یا جابه‌جا نشوند.
  ۳) پوشه کامل Shop داخل این ZIP را در محل پروژه قرار دهید.
  ۴) Shop.sln را باز کنید. حالت Debug و سپس Build > Build Solution.
     یا در PowerShell از همین پوشه:
       dotnet build .\Shop.sln --configuration Debug
  ۵) نتیجه بیلد یا متن اولین خطای کامل را برای بررسی بفرستید.

این بیلد آزمایشی است؛ Publish یا بیلد نهایی نیست.
فعلاً برای این مرحله F5، Update-Database یا دستور Seed لازم نیست.

داخل بسته:
  - Shop.Domain / Shop.Application / Shop.Infrastructure / Shop.Presentation
  - Shop.Security.Tests و Sally.AdminHash، هر دو متصل به Shop.sln
  - Landing، پنل Drag از چپ، Collection و رگال با جلو/پهلو/پشت
  - همه ۱۶ PNG اصلی کالکشن، از جمله هودی مرجع بدون تغییر بایت
  - همه ۲۴ عکس آویزان جلو/پهلو/پشت، بدون بازسازی تصویر
  - کد سبد و سفارش، حساب مشتری، بازیابی رمز، ورود مستقل مدیر و پنل‌ها
  - فایل‌های قبلی Migration بدون تغییر؛ Migration جدید اضافه نشده
  - Fixture سایز آزمایشی با Preview و محدودیت دیتابیس مستقل تست
  - گزارش وضعیت واقعی، آزمون‌ها و راهنماهای قبلی

پس از بیلد موفق:
  - آزمون‌های امنیتی مستقل از SQL اجرا شوند.
  - کپی مستقلی از ShopDb با نام SALLY_Test_20261030 آماده شود.
  - Fixture سایز ابتدا با Apply=0 فقط بررسی شود.
  - Shop.Presentation را Startup Project کنید و پروفایل SALLY_TEST را
    برای اجرای روی دیتابیس مستقل انتخاب کنید. نشانی: https://localhost:7143

تنظیم پایه اتصال همان نمونه localhost/ShopDb است. پروفایل‌های http و https
قدیمی حفظ شده‌اند؛ اجرای تست مستقل فقط با SALLY_TEST انجام شود.
اگر تنظیم خصوصی متفاوتی روی سیستم خودتان دارید، مقدارهای لازم را از بکاپ
به تنظیمات جدید منتقل کنید؛ راهنمای SALLY_TEST_PACKAGE_FA.md را بخوانید.
مدیر و SMTP رمز پیش‌فرض ندارند و باید محلی تنظیم شوند.

هیچ Build، Publish، Migration یا SQL روی دیتابیس شما در Work اجرا نشده است.
دیتابیس و فایل bak داخل این ZIP نیستند و روی سیستم شما حفظ می‌شوند.
راهنماهای قدیمی مجوز اجرای خودکار Migration یا تغییر دیتابیس نیستند.
